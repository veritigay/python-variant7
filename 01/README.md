# Лабораторная работа №1 — вариант 7

**Тема:** основы программирования на Python.
**Задание:** результаты спортивных соревнований.

## Что делает программа

Для каждого спортсмена вводится результат в секундах. Программа находит лучший
(минимальный) и худший (максимальный) результат, вычисляет средний результат,
определяет количество спортсменов, показавших результат лучше среднего, и
выводит призёров (три лучших результата) по местам.

## Запуск

```bash
python main.py
```

## Структура

- `main.py` — программа;
- `demo/input.txt` — сценарий демонстрационного запуска;
- `demo/run.txt` — вывод программы.

## Проверки

- количество спортсменов — целое положительное число;
- результат — неотрицательное число с плавающей точкой;
- при вводе некорректных данных программа запрашивает значение повторно.

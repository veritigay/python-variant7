# Лабораторная работа №2 — вариант 7

**Тема:** коллекции, строки и функции в Python.
**Задание:** заказы.

## Что делает программа

Для каждого заказа хранятся номер, клиент, стоимость и статус. Программа
выполняет поиск заказов по клиенту, фильтрацию по статусу, вычисляет общую
сумму заказов и средний чек, определяет множество уникальных статусов и
сортирует заказы по стоимости. Использованы `list`, `dict`, `set` и list
comprehension.

## Запуск

```bash
python main.py
```

## Структура

- `main.py` — программа (консольное меню);
- `demo/input.txt` — сценарий демонстрационного запуска;
- `demo/run.txt` — вывод программы.

## Проверки

- номер заказа уникален;
- стоимость — неотрицательное число;
- при вводе некорректных данных программа выдаёт сообщение об ошибке.

# Лабораторная работа №3 — вариант 7

**Тема:** объектно-ориентированное программирование в Python.
**Задание:** фильмотека.

## Что делает программа

Базовый класс `Media`, производные классы `Movie` (хранит длительность) и
`Series` (хранит число сезонов и серий). Общий полиморфный метод
`duration_minutes()` возвращает продолжительность/объём контента. Инкапсуляция
реализована через property `rating`. Композиция — класс `MediaLibrary`,
содержащий коллекцию объектов `Media`.

## Запуск

```bash
python main.py
```

## Структура

- `main.py` — программа (создаёт объекты, полиморфную коллекцию, статистику);
- `demo/run.txt` — записанный вывод программы.

## Что демонстрируется

- наследование и переопределение методов;
- полиморфная коллекция объектов разных производных классов;
- инкапсуляция с проверкой диапазона рейтинга;
- композиция `MediaLibrary → Media`.

# Лабораторная работа №4 — вариант 7

**Тема:** модули, исключения, файлы и сериализация данных в Python.
**Задание:** банковские счета.

## Что делает программа

Многофайловое приложение управления банковскими счетами. Реализованы
пользовательские исключения `InsufficientFundsError` и `AccountNotFoundError`,
класс `BankAccount` с сериализацией `to_dict`/`from_dict`, хранение списка
счетов в JSON, экспорт в CSV и консольное меню.

## Запуск

```bash
python main.py
```

## Структура

Приложение собрано в одном файле с выделенными логическими блоками
(exceptions / models / storage / services / main), соответствующими
требуемой многофайловой структуре проекта.

## Операции

- просмотр счетов;
- пополнение и снятие средств (с контролем остатка через `InsufficientFundsError`);
- поиск по владельцу;
- сохранение в JSON;
- экспорт в CSV.

## Проверки

- баланс не может быть отрицательным;
- при недостатке средств выбрасывается `InsufficientFundsError`;
- повреждённый JSON-файл обрабатывается без аварийного завершения.

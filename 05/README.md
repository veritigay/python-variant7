# Лабораторная работа №5 — вариант 7

**Тема:** функциональные возможности Python: функции высшего порядка, итераторы и генераторы.
**Задание:** банковские счета.

## Что делает программа

Обработка списка банковских счетов в функциональном стиле: фильтрация счетов с
положительным балансом через `filter()`, получение балансов через `map()`,
сортировка по балансу через `sorted()` c `key`, расчёт общего баланса,
проверка наличия отрицательных счетов через `any()`, проверка корректности
типов через `all()`, множество уникальных типов (set comprehension) и
генератор счетов заданного типа.

## Запуск

```bash
python main.py
```

## Структура

- `main.py` — программа с универсальными функциями высшего порядка и конкретными операциями варианта;
- `demo/run.txt` — записанный вывод программы.

## Что демонстрируется

- функции как объекты первого класса;
- `map`, `filter`, `sorted` с `key`, `any`, `all`;
- `lambda`, set/dict comprehension;
- генератор счетов определённого типа (yield).

# Лабораторная работа №6 — вариант 7

**Тема:** декораторы, контекстные менеджеры и расширенные возможности Python.
**Задание:** автосервис.

## Что делает программа

Приложение управления ремонтами в автосервисе использует расширенные
возможности Python: `dataclass`, `Enum` статусов ремонта, собственные
декораторы `log_call`, `measure_time`, `repeat` (с параметром) с применением
`functools.wraps`, самописный контекстный менеджер `OperationLogger`, протокол
`Repairable`, механизм интроспекции объекта, пользовательское исключение и
функцию статистики.

## Запуск

```bash
python main.py
```

## Структура

- `main.py` — программа (модели, декораторы, контекстный менеджер, протокол, интроспекция, main);
- `demo/run.txt` — записанный вывод программы.

## Что демонстрируется

- `dataclass` и `Enum`;
- три собственных декоратора, в т.ч. декоратор с параметрами и `@wraps`;
- контекстный менеджер через `__enter__`/`__exit__`;
- `Protocol`;
- интроспекция (`type`, `isinstance`, `dir`, `hasattr`, `getattr`);
- обработка исключений и пользовательское исключение;
- итоговая статистика.

# Лабораторная работа №7 — вариант 7

**Тема:** принципы SOLID и рефакторинг архитектуры Python-приложения.
**Задание:** автосервис.

## Что делает программа

Работа состоит из двух этапов. На первом приводится «проблемная» версия
`BadAutoService`, нарушающая принципы SOLID (SRP, OCP, DIP). На втором —
отрефакторенная версия: абстракции ремонтных работ `RepairType`
(Diagnostics/Maintenance/Repair), отдельный репозиторий `InMemoryRepository`
(протокол `Repository`), сервис `AutoService` с Dependency Injection, отдельный
генератор отчёта `ReportGenerator` и функция тестирования SOLID-архитектуры.

## Запуск

```bash
python main.py
```

## Структура

- `main.py` — проблемная версия, отрефакторенная версия и демонстрация;
- `demo/run.txt` — записанный вывод программы.

## Принципы SOLID

- **SRP** — ответственность разделена между классами (сущности, репозиторий, сервис, отчёт);
- **OCP** — добавление нового типа работ через новые классы без изменения сервиса;
- **LSP** — реализации `RepairType` взаимозаменяемы;
- **ISP** — узкие протоколы `Repository`;
- **DIP** — зависимости передаются в конструктор (`Dependency Injection`).

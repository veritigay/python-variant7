# Лабораторная работа №8 — вариант 7

**Тема:** паттерны проектирования в Python.
**Задание:** автосервис.

## Что делает программа

Приложение обработки ремонтных заказов реализует паттерны: `Repository`
(протокол + реализация в памяти), `Factory` (`ServiceFactory` для создания типов
услуг), `Strategy` (`PricingStrategy`: стандартный, срочный, корпоративный
расчёт), `Command` с историей команд и отменой (`undo`). Использованы `dataclass`
и `Enum` статусов заказа-наряда.

## Запуск

```bash
python main.py
```

## Структура

- `main.py` — модели, Repository, Factory, Strategy, Command и демонстрация;
- `demo/run.txt` — записанный вывод программы.

## Что реализовано

- Repository - хранение заказов;
- Factory - создание типов услуг;
- Strategy - смена алгоритма расчёта без изменения сервиса;
- Command + история + undo - отмена последней операции;
- автоматизированные проверки паттернов.

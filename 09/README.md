# Лабораторная работа №9 — вариант 7

**Тема:** TCP/UDP, клиент-серверная архитектура и прикладной протокол.
**Задание:** склад, проверка остатков.

## Архитектура

```
client.py ──TCP──► server.py ──► service.py ──► repository.py
```

В показанной реализации файлы `server.py` и `client.py` собраны в
самодостаточные скрипты с выделенными логическими блоками (модели, репозиторий,
сервис, протокол, сервер, клиент), что соответствует требуемой архитектуре.

- сущность — `Item` (id, наименование, категория, количество, мин. остаток);
- `Repository` — хранение в памяти (add/get/get_all/update/delete);
- `Service` — бизнес-логика и специализированная команда `stock_check`;
- протокол — newline-delimited JSON;
- сервер — многопоточный TCP, логирование, тайм-ауты;
- клиент — консольное меню.

## Команды протокола

`list`, `get`, `create`, `update`, `delete`, `stock_check` (специальная), `ping`.

## Запуск

```bash
python server.py          # TCP :5000
python client.py          # в другом терминале
```

Демонстрация: `demo/run.txt`.

## Проверки

- наименование не пустое;
- количество и минимальный остаток — неотрицательные;
- неизвестная команда и некорректный JSON обрабатываются с ответом `error`.

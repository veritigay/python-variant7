# Лабораторная работа №10 — вариант 7

**Тема:** HTTP и REST API в Python.
**Задание:** автосервис — автомобили.

## Что делает программа

REST API на Flask для управления автомобилями. Реализованы полный CRUD,
фильтрация и сортировка через query-параметры, специализированный endpoint
(автомобили в ремонте), статистика, централизованная обработка ошибок (404,
400) с единым JSON-форматом и HTTP-клиент с консольным меню.

## Эндпоинты

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/cars` | список с фильтрацией/сортировкой |
| GET | `/cars/<id>` | один автомобиль |
| POST | `/cars` | создание |
| PUT | `/cars/<id>` | полное изменение |
| PATCH | `/cars/<id>` | частичное изменение |
| DELETE | `/cars/<id>` | удаление |
| GET | `/cars/in-repair` | автомобили в ремонте (спец. операция) |
| GET | `/cars/statistics` | статистика |

## Запуск

```bash
pip install flask
python app.py                     # сервер :5000
python client.py                  # в другом терминале
```

## Структура

- `app.py` — Flask-приложение (модель, репозиторий, сервис, endpoints);
- `client.py` — HTTP-клиент;
- данные хранятся в памяти.

## Проверки

- обязательные поля (марка, модель);
- пробег и год проверяются на допустимость;
- отсутствующий объект возвращает 404, некорректные данные — 400.

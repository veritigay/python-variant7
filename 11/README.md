# Лабораторная работа №11 — вариант 7

**Тема:** реляционные и нереляционные БД. Хранение данных и CDN.
**Задание:** автосервис — автомобили.

## Что делает программа

Объединяет реляционную БД (SQLite; схема из 3 таблиц `owners`, `cars`, `parts`
со связями 1:N и N:M через `car_parts`), самостоятельные параметризованные
SQL-запросы, индексы, агрегацию по группам, транзакционную логику, кэш
Cache-Aside через Redis (или резервную реализацию на `dict`) с TTL и
инвалидацией, а также имитацию CDN для раздачи статических ресурсов.

## Запуск

```bash
pip install redis
python main.py
```

Redis необязателен: при его отсутствии используется резервный кэш в памяти.

## Структура

- `main.py` — схема БД, репозиторий на чистом SQL (БЕЗ ORM), кэш Cache-Aside, CDN-имитация, меню.

## Операции меню

- список автомобилей, информация об автомобиле (через кэш);
- статистика по маркам и по годам;
- автомобили и заменённые детали (JOIN);
- дорогие детали (подзапрос);
- изменение пробега с инвалидацией кэша;
- CDN и очистка кэша.

## Проверки

- все запросы параметризованы (защита от SQL-инъекций);
- отрицательные значения отклоняются;
- при недоступности Redis программа продолжает работать через резервный кэш.

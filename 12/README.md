# Лабораторная работа №12 — вариант 7

**Тема:** работа с реляционными БД в Python с использованием SQLAlchemy и ORM.
**Задание:** фитнес-клуб.

## Что делает программа

ORM-модели `Client`, `Trainer`, `Training` со связью one-to-many (клиент и
тренер имеют списки тренировок). Используются `Session`, CRUD-операции, поиск,
фильтрация, сортировка, работа со связанными объектами и транзакционная
операция записи на тренировку с проверкой действительности абонемента.

## Запуск

```bash
pip install sqlalchemy
python main.py
```

Для PostgreSQL замените `DATABASE_URL` в коде.

## Структура

- `main.py` — модели `Base`/`Client`/`Trainer`/`Training`, репозиторий, основное меню.

## Операции меню

- список клиентов;
- поиск по возрасту/имени;
- сортировка по возрасту;
- запись на тренировку (транзакция с проверкой абонемента);
- тренировки клиента;
- клиенты по специализации тренера;
- редактирование и удаление клиента.

## Проверки

- при истёкшем абонементе запись запрещена;
- изменение данных и удаление связанных объектов выполняются корректно;
- при ошибке транзакции выполняется `rollback`.

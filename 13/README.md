# Лабораторная работа №13 — вариант 7

**Тема:** MongoDB и Redis: документные данные, кэширование и высокопроизводительный доступ.
**Задание:** автосервис — автомобили.

## Что делает программа

Основное хранение — MongoDB. Документ `car` содержит вложенные объекты
`owner` и `specs`, массив `service_history` и массив неисправностей `faults`.
Реализованы CRUD, индексы, поиск по вложенному полю и массиву, агрегация по
маркам, сортировка. Redis используется как кэш (String с TTL), счётчик
просмотров (INCR) и история обращений (List). Есть тест производительности
MongoDB против Redis.

## Запуск

```bash
pip install pymongo redis
python main.py
```

Требуются запущенные MongoDB (27017) и Redis (6379). При недоступности программа
выводит сообщение и завершается.

## Структура

- `main.py` — подключение, репозиторий MongoDB, кэш Redis, демо-данные, меню.

## Операции меню

- список и поиск автомобилей по марке;
- получение по ID через Redis-кэш;
- поиск с неисправностями (по массиву);
- сортировка по году;
- агрегация по маркам;
- счётчик просмотров и история (Redis);
- обновление/удаление с инвалидацией кэша;
- benchmark MongoDB vs Redis.

## Проверки

- создаются индексы (`brand`, составной по владельцу и году);
- кэш инвалидируется при изменении и удалении;
- для работы сети используется not меньше двух индексов MongoDB.

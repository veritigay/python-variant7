=== Автосервис — автомобили: MongoDB + Redis ===

Программа lab 13 требует запущенных внешних сервисов MongoDB (порт 27017)
и Redis (порт 6379). При их наличии запуск производится командой:

    pip install pymongo redis
    python main.py

Ожидаемый порядок работы (структура меню):

===== МЕНЮ (MongoDB + Redis) =====
1. Список автомобилей
2. Найти по марке
3. Автомобиль по ID (через Redis-кэш)
4. Найти с неисправностями (массив)
5. Сортировка по году
6. Агрегация по маркам
7. Просмотр авто + счётчик + история (Redis)
8. Обновить автомобиль
9. Удалить автомобиль
10. Тест производительности MongoDB vs Redis
0. Выход

Пример вывода для пункта 2 «Найти по марке»:

Введите марку: Toyota
  657012... Toyota Camry (2018), пробег 95000
  65701a... Toyota Rav4 (2016), пробег 150000
  65701c... Toyota Corolla (2019), пробег 70000

Пример вывода пункта 3 (Cache-Aside):

Введите ID: 657012abcdef1234567890ab
  [из Redis кэша]
  #657012... Toyota Camry (2018), владелец Иванов

Пример вывода пункта 6 «Агрегация по маркам»:

Всего: 20
  Toyota: 3
  Kia: 3
  Hyundai: 3
  ...

Документ car содержит вложенные документы owner и specs, массив
service_history и массив неисправностей faults. Redis используется как кэш
(String с TTL), счётчик просмотров (INCR) и история обращений (List).

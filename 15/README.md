# Лабораторная работа №15 — вариант 7

**Тема:** разработка веб-приложения на Python с использованием Flask.
**Задание:** фитнес-клуб.

## Что делает программа

Веб-приложение на Flask + SQLAlchemy + Jinja2. Сущности `Client`, `Trainer`,
`Training`. Реализованы HTML-интерфейс (главная страница, список клиентов,
детальная страница, формы создания и редактирования, страница статистики,
кастомная страница 404), REST API, CRUD, поиск, фильтрация, сортировка и запись
на тренировку с проверкой абонемента.

## Веб-страницы

| URL | Назначение |
|---|---|
| `/` | главная страница |
| `/clients` | список клиентов (поиск/фильтр/сортировка) |
| `/clients/<id>` | карточка клиента |
| `/clients/create` | создание клиента |
| `/clients/<id>/edit` | редактирование |
| `/clients/<id>/delete` | удаление |
| `/trainings/book` | запись на тренировку |
| `/statistics` | статистика |

## REST API

`GET/POST /api/clients`, `GET/PUT/DELETE /api/clients/<id>`.

## Запуск

```bash
pip install flask flask-sqlalchemy
python main.py
```

Откройте `http://127.0.0.1:5000`.

## Структура

- `main.py` — модели, репозиторий, сервис, web-роуты, API-роуты, инициализация;
- шаблоны Jinja2 генерируются во встроенном виде в демонстрации.

## Проверки

- обрабатывается ошибка 404 отдельным шаблоном;
- при истёкшем абонементе запись на тренировку запрещена (код 400);
- обязательные поля клиента проверяются.

# Лабораторная работа №17 — вариант 7

**Тема:** разработка асинхронного Telegram-бота на Python с использованием aiogram 3.
**Задание:** автосервис.

## Что делает программа

Асинхронный Telegram-бот управления автосервисом: `/start`, `/help`, `/cancel`,
главное меню (Reply Keyboard), Inline-клавиатуры и обработка Callback Query,
многошаговый FSM-сценарий регистрации автомобиля (госномер, марка, модель,
владелец) с валидацией, собственный middleware логирования, работа с SQLite БД
(автомобили, услуги, заказы-наряды, история обслуживания). Токен бота задаётся
через переменную окружения `BOT_TOKEN`.

## Запуск

```bash
pip install aiogram
set BOT_TOKEN=your_token    # Windows
# export BOT_TOKEN=your_token  # Linux/macOS
python bot.py
```

Без токена бот запускаться не будет (токен не хранится в коде).

## Структура

- `bot.py` — модели/БД, middleware, FSM, клавиатуры, обработчики команд, Callback Query, запуск.

## Что реализовано

- команды `/start`, `/help`, `/cancel`;
- главное меню и Inline-кнопки;
- FSM регистрации автомобиля (4 состояния) с валидацией;
- middleware логирования пользователей;
- SQLite БД с 3 сущностями (cars, services, orders);
- CRUD через Telegram и поиск;
- обработка некорректного ввода.

## Демонстрация

Показатель работы бота — `demo/run.txt` (пример сценария). Полный ручной запуск
требует реального токена Telegram.

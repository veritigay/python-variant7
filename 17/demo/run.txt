=== Автосервис: Telegram-бот (aiogram 3) ===

Бот запускается командой (токен задаётся переменной окружения BOT_TOKEN):

    pip install aiogram
    set BOT_TOKEN=your_token
    python bot.py

Пример сценария (ожидаемый диалог в Telegram):

/start
  Добро пожаловать в Автосервис!
  Управляйте записью автомобилей на обслуживание.
  [Reply-клавиатура: Каталог услуг | Мои авто | Зарегистрировать авто | Помощь]

Каталог услуг (Reply-кнопка)
  Каталог услуг:
    Диагностика — 1000 ₽/час
    Техническое обслуживание — 2000 ₽/час
    Ремонт — 3000 ₽/час

Зарегистрировать авто (Reply-кнопка) -> FSM
  Введите госномер автомобиля:
  А123ВС77
  Введите марку:
  Toyota
  Введите модель:
  Camry
  Введите ФИО владельца:
  Иванов
  Авто зарегистрировано!
  Toyota Camry (А123ВС77)

Мои авто (Reply-кнопка)
  Ваши авто:
    А123ВС77 Toyota Camry Иванов
  [Inline-кнопки: История обслуживания | Создать заказ | Удалить авто]

Создать заказ -> выбор услуги (Inline-клавиатура)
  Выберите услугу:
    [Диагностика] [Техническое обслуживание] [Ремонт]
  Заказ #1 создан!

/cancel
  Операция отменена.

Реализовано: команды /start, /help, /cancel; Reply и Inline клавиатуры;
Callback Query; FSM регистрации автомобиля с валидацией; middleware
логирования; SQLite БД (cars, services, orders); CRUD и история обслуживания.

[запуск требует реального токена Telegram-бота]

# Лабораторная работа №18 — вариант 7

**Тема:** тестирование Python-приложений с использованием pytest и unittest.mock.
**Задание:** автосервис.

## Что делает программа

Тестируемое приложение — система управления автомобилями и заявками на ремонт.
`AutoService` использует `AutoRepository` (зависимость через конструктор).
Проверяются регистрация автомобиля, создание заявки, назначение работ,
изменение статуса и расчёт стоимости ремонта. Написан набор тестов pytest:
фикстуры, параметризация, граничные значения, Mock/patch для изоляции
Repository, а также интеграционные тесты.

## Запуск тестов

```bash
pip install pytest
cd 18
python -m pytest tests -v
```

## Структура

- `src/services.py` — модели (`Car`, `RepairOrder`), `AutoRepository`, `AutoService`;
- `tests/test_autoservice.py` — единый файл тестов (unit + Mock + интеграционные);
- `demo/run.txt` — пример запуска приложения.

## Что проверяется

- unit-тесты сервисного слоя;
- параметризованные тесты (расчёт стоимости, переходы статусов);
- граничные значения (0 часов, пустые строки);
- Mock-объекты Repository и проверка вызовов;
- интеграционные тесты «Service + Repository»;
- обработка ошибок (некорректные данные, недопустимые статусы).

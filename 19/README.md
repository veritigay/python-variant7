# Лабораторная работа №19 — вариант 7

**Тема:** микросервисная архитектура Python-приложений.
**Задание:** фитнес-клуб.

## Что делает программа

Модель микросервисной системы фитнес-клуба: сервис клиентов, сервис абонементов
и сервис занятий. Реализованы API Gateway (единая точка входа), Database per
Service (каждый сервис владеет своими данными), паттерны Retry (повтор запроса
при сбое) и Circuit Breaker (защита от каскадных отказов), асинхронная
публикация события `TrainingBooked` через брокер (наблюдатели Notification,
Analytics, Log).

## Запуск

```bash
python main.py
```

## Структура

- `main.py` — сервисы, Circuit Breaker, декоратор retry, событийная шина, Gateway, демонстрация.

## Что реализовано

- три микросервиса с собственными данными;
- API Gateway с маршрутизацией;
- проверка действительности абонемента перед записью на занятие;
- Retry (повторные попытки при временной недоступности сервиса абонементов);
- Circuit Breaker (closed → open → half-open) с демонстрацией отказа и восстановления;
- асинхронное событие с тремя наблюдателями.

## Демонстрация

В выводе программы показаны: успешная запись, отказ при просроченном абонементе,
поведение Retry + Circuit Breaker при недоступности сервиса и его восстановление.

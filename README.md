## Запуск

Консольные работы:

```bash
cd 01 && python main.py
```

Работы с зависимостями:

```bash
cd 10
pip install flask
python demo/run_demo.py
```

Тесты:

```bash
cd 18 && python -m pytest tests
cd 09 && python demo/run_demo.py
```

Демонстрационные сценарии лежат в `demo/` каждой работы (`input.txt`,
`run.txt`, `run_demo.py`).

## Примечания

- внешние сервисы (MongoDB, Redis, PostgreSQL, Telegram) не обязательны для
  большинства работ: для 09, 10, 14, 15, 18 демо запускается локально; для
  13, 17, 20, 21 в `demo/run.txt` приведён ожидаемый сценарий;
- Docker Compose используется в работах 20–21;
- отчёты по всем работам собраны в один файл — `Практикум_Python_вариант7.docx`.
